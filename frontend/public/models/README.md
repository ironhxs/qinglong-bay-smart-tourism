# 青龙湾AR场景3D模型

本目录用于存放青龙湾AR场景所需的3D模型文件。

## 支持的模型格式

- GLB/GLTF (推荐): 轻量级二进制格式，包含几何体、材质、动画和场景结构
- OBJ+MTL: 简单的几何体和材质格式
- FBX: 包含高级动画和骨骼的格式

## 模型命名规范

请按照以下命名规范存放模型文件：

- `huizhou-building.glb`: 徽派建筑模型
- `ancient-bridge.glb`: 青龙湾古桥模型
- `traditional-pavilion.glb`: 传统亭台模型
- `cultural-artifact.glb`: 文物模型(如徽墨、歙砚等)

## 模型要求

1. **文件大小**: 单个模型文件不超过5MB，以确保快速加载
2. **多细节层次(LOD)**: 提供不同细节级别的模型版本
3. **优化**: 模型应经过优化，减少面数和材质数量
4. **UV映射**: 正确的UV映射以确保纹理正确显示
5. **比例**: 使用真实世界比例

## 使用说明

系统会自动加载相应的模型文件。如果模型文件不存在，系统将显示默认的占位几何体。

## 青龙湾特色模型

请特别注意添加以下青龙湾特色模型：

1. **青龙湾古桥**: 具有徽州特色的石拱桥
2. **徽派建筑群**: 包含马头墙、雕花窗等特色元素
3. **非遗文化展示**: 如徽墨制作工艺、徽州剪纸等
4. **生态景观**: 青龙湾特有的自然风光

## 模型来源

模型可以通过以下方式获取：

1. 使用3D建模软件(如Blender)创建
2. 从3D模型资源网站购买或下载免费模型
3. 使用摄影测量技术从实物创建
4. 通过AI生成工具创建基本模型
